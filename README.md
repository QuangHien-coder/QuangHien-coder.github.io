# Học HTML

Mỗi buổi học tạo 1 thư mục mới: `bai-02`, `bai-03`... (copy `bai-01` rồi đổi tên).
Mỗi bài có sẵn `css/`, `img/`, `js/`. Ảnh để trong `img`, gọi bằng `img/ten-anh.jpg`.

## Cách xem trang
- Cách nhanh: chuột phải `index.html` → **Open with Live Server** (cài extension *Live Server* trong VS Code). Sửa code, lưu là trang tự tải lại.
- Hoặc nháy đúp `index.html` để mở bằng trình duyệt.

## Mẹo VS Code
- Gõ `!` rồi Enter trong file `.html` trống → tự có khung HTML.
- `Alt + Shift + F` → căn lề code cho đẹp.
