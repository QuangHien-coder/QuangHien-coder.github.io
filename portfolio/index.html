Phạm Quang Hiển

Mình học làm ứng dụng di động với Flutter, cùng với Java hướng đối tượng và Python. Mình thích làm ra những app gọn, dễ dùng và chạy ổn định.

Xem dự án GitHub

Giới thiệu

Mình là sinh viên lập trình phần mềm tại Aptech, lớp T2608E. Mình bắt đầu viết code bằng C từ năm 2024, khi ôn đội tuyển Tin học ở trường, rồi chuyển sang Java hướng đối tượng, Python và làm ứng dụng di động với Flutter.

Tháng 9/2026, mình cùng nhóm 5 người làm app HarvestHub cho cuộc thi TechWiz 7 và phụ trách các màn hình phía nông dân. Mục tiêu tiếp theo của mình là tự làm trọn một app, từ thiết kế giao diện, frontend đến backend.

Hiện tại mình đang

  • Tự làm app quản lý chi tiêu PennyPal bằng Flutter
  • Học thiết kế giao diện (UI/UX) cho app di động
  • Học Java hướng đối tượng, HTML và CSS trên lớp
